AI 解读

尚未起盘
钥匙不落他人手。线上完整版的解读由服务端调模型，静态页没有服务端，所以这里改成 你自带 API Key、浏览器直连厂商：Key 只写进你自己这台浏览器的 localStorage， 请求直接发往厂商域名，不经过本站的任何服务器，也不会被上传到仓库。 不想在本机留痕就别勾「记住」。
填好 Key，点「开始解读」。先生会先给一段盘面速览和几条先验锚点，再顺着你的回答往下问；也可以在「想细看的方向」里直接点一个方向，让他跳过提问直奔分析。
关于这个 Demo：排盘是确定性的历法计算，与线上版同源——八字引擎在 200 例测评集上四柱、日主、生肖、空亡、地势逐项 100% 一致； 印占引擎改用瑞士星历的 WebAssembly 版本（与线上同一套星历与口径）在浏览器里复算，13 项盘面要素、真恒星年、九步 Vimshottari 大运 与次运边界均已逐项对齐。
与线上完整版的差别只有两处：解读改由你自带 Key 直连模型，档案与登录这类需要服务端存储的功能在静态页上无法提供。
印占首次使用需要下载约 2.7 MB 的瑞士星历（这是口径一致的硬成本），页面打开后会在后台自动预载， 之后由浏览器缓存，不再重复下载。命理内容仅供文化体验与娱乐参考。
